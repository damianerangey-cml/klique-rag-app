# Accounts and single sign-on

## User roles

Pellwood Cloud has three roles. A viewer can see dashboards. An operator can also acknowledge alerts and edit zones. An administrator can also manage users, billing and firmware.

## Single sign-on

Single sign-on with SAML 2.0 or OpenID Connect is available on the Enterprise plan. Once single sign-on is enforced for a site, password sign-in is disabled for every user except one break-glass administrator account.
