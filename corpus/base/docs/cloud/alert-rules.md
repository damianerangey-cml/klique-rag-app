# Alert rules

## Creating a rule

An alert rule watches one measurement in one zone. A rule has a threshold, a direction (above or below) and a duration. For example: temperature above 32 degrees Celsius for 10 minutes.

## Notifications

Alerts are delivered by email, SMS and mobile push notification. SMS delivery is limited to 200 messages per site per month. An alert that is not acknowledged within 30 minutes is escalated to the next contact in the escalation list.
