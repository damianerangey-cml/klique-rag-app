# Sense S1 specifications

## Measurement

The Sense S1 measures air temperature from -20 to 60 degrees Celsius and relative humidity from 0 to 100 percent. The default reporting interval is 5 minutes and can be set between 1 and 60 minutes.

## Physical

The sensor weighs 95 grams including batteries and is rated IP65. It has one accessory port for a Probe M3 soil moisture probe.
