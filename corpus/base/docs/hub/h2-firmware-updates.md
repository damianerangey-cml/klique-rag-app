# Hub H2 firmware updates

## Automatic updates

The Hub H2 checks for new firmware every night at 02:00 local time. Updates are installed automatically when no alert is active. The status light blinks white during installation, which takes about six minutes.

## Manual updates and pinning

An administrator can start an update at any time from Pellwood Cloud under Site settings, Hub, Firmware. A site can be pinned to a firmware version for up to 60 days, after which automatic updates resume.
