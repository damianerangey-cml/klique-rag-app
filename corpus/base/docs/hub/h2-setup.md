# Hub H2 first-time setup

## Before starting

The Hub H2 needs mains power and an Ethernet or Wi-Fi connection. Install the Pellwood mobile app and sign in before powering the hub.

## Setup steps

1. Plug in the hub and wait until the status light blinks blue.
2. In the mobile app choose Add hub and scan the QR code on the underside of the hub.
3. Select the network connection. Ethernet is detected automatically.
4. Name the site and the first zone.

Setup normally takes about four minutes. The hub downloads the latest firmware during setup and restarts once.
