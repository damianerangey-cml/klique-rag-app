# Hub H2 status light

## Light colours

The status light on the front of the Hub H2 shows the current state.

- Blinking blue: the hub is in setup mode and waiting for the mobile app.
- Solid green: the hub is connected to Pellwood Cloud.
- Blinking amber: the hub has a network connection but cannot reach Pellwood Cloud.
- Solid red: a hardware fault. Contact support.
- Blinking white: a firmware update is being installed. Do not unplug the hub.

## Turning the light off

The light can be dimmed or turned off in Pellwood Cloud under Site settings, Hub, Status light.
