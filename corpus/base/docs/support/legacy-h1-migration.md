# Migrating from the legacy Hub H1

## End of support

The legacy Hub H1 is no longer sold. It stays supported until the end of the current year, after which it stops receiving firmware updates.

## Migration steps

Sensors paired with a Hub H1 must be paired again with a Hub H2. Historical readings stay in Pellwood Cloud because they belong to the zone and not to the hub. Customers migrating from a Hub H1 receive a trade-in discount of 20 percent on a Hub H2.
