# Troubleshooting a sensor that shows as offline

## What offline means

Pellwood Cloud marks a sensor as offline when it has missed three consecutive reporting intervals.

## Checks

1. Check the battery level in the last reading. Replace the batteries if it was below 15 percent.
2. Check the distance to the hub or to the nearest mesh hop.
3. Check that the hub status light is solid green.
4. Press the pairing button on the sensor once. The sensor light blinks green twice if it can reach the hub and red twice if it cannot.

If the sensor still shows as offline after these checks, contact support with the sensor serial number.
