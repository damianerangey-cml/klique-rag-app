# Glossary

## Terms used in Pellwood documentation

- Zone: a named area of a greenhouse. Every sensor belongs to exactly one zone.
- Reading: one measurement sent by a sensor, with a timestamp.
- Reporting interval: the time between two readings from the same sensor.
- Site: a physical location with one or more hubs. A site is the unit of billing.
- Mesh hop: a sensor relaying the readings of another sensor toward the hub.
