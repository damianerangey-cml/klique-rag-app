# Pellwood product lineup

Pellwood makes monitoring equipment for commercial greenhouses. All products and figures in this document set are fictional and exist only as sample data.

## Hardware

The lineup has three hardware products. The Hub H2 is the gateway that connects sensors to Pellwood Cloud. The Sense S1 is a wireless temperature and humidity sensor. The Probe M3 is a wired soil moisture probe that plugs into a Sense S1.

## Software

Pellwood Cloud is the web application for dashboards, alert rules and data export. The Pellwood mobile app is used for first-time setup and pairing.
